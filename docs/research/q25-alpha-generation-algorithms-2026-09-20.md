# Q25：以组合改善为目标的 alpha 生成算法

日期：2026-09-20。检索范围：2025 年至本日的 alpha 挖掘、符号回归、动力系统发现及时间序列解释方法。
本文是算法研究与可实现规格，不是新搜索器已上线的声明。论文结果、Q25 现状和本文建议分别标明。

## 1. 结论与纠正

此前的“C++ 文法生成、变异、交叉”就是**带类型约束的遗传规划（GP）**。C++ 是实现语言，不是算法创新。
GP 应保留为必须击败的基线，而不是用新名词包装成最终答案。

建议优先验证的算法是：**以当前组合为条件的 GFlowNet 表达式生成器，用共同后续补全进行动作反事实比较，以真实组合净收益作为终端奖励。**
外层采用逐次添加构件并重新优化权重的组合搜索。这里有三个明确的算法选择：

1. GFlowNet 学习一个可批量采样、保留多个高价值模式的表达式分布。
2. 配对反事实比较把完整回测反馈分配给具体的字段、算子、窗口选择，增加每次回测的训练价值。
3. 奖励是相对于当前组合的真实净收益改善，低相关约束也根据真实收益行为计算。

这不是照抄某篇论文：AlphaSAGE/AlphaG-OPD 的奖励不是 Q25 净组合目标，AlphaQCM/AlphaRJM 的组合 IC 也不是交易收益。
**组合条件、净收益奖励、G1/G2、相关性规则以及参照版本管理是本项目需要实现和验证的改造。**
尚无本机实验证据证明这个组合优于 GP、交叉熵法或直接强化学习；下面给出可否证的对照实验。

## 3. 先把 Q25 的优化问题写清楚

### 已实现的评价对象

当前组合为 P，候选表达式 x 产生持仓 A(x)。现有评价按：

    H(w) = (1-w)P + w A(x)
    r(w) = BacktestNet(H(w))

其中 BacktestNet 必须重新计算真实持仓演化、交易成本和净收益，不能用两个单体净收益向量加权冒充。
现有 G2 寻找满足以下约束的权重：

    Δ近期加权 Sharpe ≥ 0.01
    Δ全期 Sharpe ≥ 0
    ΔCAGR ≥ 0
    Δ近期加权年化对数增长 ≥ 0

还有有效收益、容量及成员规则。G1 是结构/因果/数值有效性；当前 ts_rank 窗口超过 31 有已知前视实现问题，不能生成。
G2 的 0.01 是工程改善幅度，不是统计显著性。

现有代码在可行权重中先最大化近期加权 Sharpe，再以 CAGR 打破相等项。这不是同时自由优化所有旧成员权重。
**目前是一次一条的受约束添加搜索；奖励指向组合，并不自动成为全局组合最优算法。**

### 建议用于生成器的明确奖励

保留 G1/G2 为准入约束；训练信号另外定义，不能把训练分数当作通过 gate。
设四个约束的有符号裕量为 m_j(x,w)，阈值已经扣除。对可行权重建议计算：

    U(x,w | P) = 0.5 tanh(ΔS_recent / s_S)
               + 0.5 tanh(Δg_recent / s_g)

这是对“Sharpe 与收益兼顾”的一个明确起点。s_S、s_g 是各自有意义的改善尺度，按训练数据预先设定，不能逐 batch 漂移。
完整 Sharpe/CAGR 已由硬约束守住；两项不再简单相加不同单位的原始数值。
生成奖励可在所有满足约束的 w 上最大化 U。若上线这种选权，需明确修改现有“Sharpe 优先”的选权规则并单独验收，不能只改训练侧却宣称生产选择一致。

令 V(x)=min_w Σ_j max(0,-m_j(x,w)/s_j)，每个权重的所有约束一起计算后再取最小值，禁止拼接不同权重的最佳指标。
一个可复现实验的正奖励定义是：

    log R = -12                                      G1 失败或没有有效组合试探
    log R = -6 - min(4,V(x)+V_corr(x))               G1 通过但准入/相关性约束不可行
    log R = 1 + 3 sigmoid(U - λ_tail D_tail
                         - λ_len L - λ_dup D_dup)   存在完全可行权重

R=exp(log R)，因此可用于 TB。L、D 各项先归一化，系数只在训练选择阶段调整。
低分的失败样本仍可用于学习“哪里接近可行”，但不能进入正式组合。
每条可行公式的奖励较高，**不代表可行集合的总采样概率必然高**：无效结构数量可能巨大，必须实测通过率，并控制重复行为占据的概率质量。
这套数值是本文建议的起始规格，不是论文给出的最优参数。

## 4. “低相关”要落在行为上

至少保存三类相关性，使用一致的交易日期、成本口径和有效观测区间：

1. 候选净收益与当前组合、各成员净收益的相关性，保留正负号。
2. 批内候选之间的相关性，避免一次生成 100 个近乎相同的候选。
3. 组合下跌日的候选亏损幅度/共同亏损频率，避免全期相关低而危机期同时失效。

对“低相关构件”明确使用约束：

    ρ_plus(x) = max(0, corr(r_x,r_P), max_i corr(r_x,r_i)) ≤ ρ_max

ρ_max 应成为显式实验参数；例如比较 0.8、0.9 与只作惩罚三种预登记设置，不以事后最优结果无限调参。
超过上限但通过原 G2 的候选可以进入研究记录，不能被标成满足“低相关准入”。当前生产 G2 尚无此硬约束，本文没有悄悄更改它。
最终采纳哪一种上限，应看固定预算下的组合改善和保留的对冲价值，而非只看相关性分布漂亮。

不能无区别惩罚 |ρ|：负相关构件可能是很好的对冲。需要另外标记绝对相关接近 1 的镜像行为，结合 long-only 持仓与成本判断能否复用。
与已有成员收益张成空间的投影 R²、对市场暴露回归后的残差相关可用作诊断，但不替代原始相关；高 R² 也不自动意味着没有对冲价值。
全现金/近零波动序列的相关性没有定义，不能把它填成 0 后授予多样性奖励。

档案还保存持仓指纹及真实持仓距离。完全相同持仓只保留一个代表，近似相同的行为按簇限额。
收益相关只是摘要，不足以证明持仓等价。最终去重须核对持仓、时域和交易掩码。
一次接受候选后，其他候选相对于新成员的相关性也必须更新。

## 5. 表达式究竟怎么生成

### 状态、动作和网络

采用**前序、最左未完成槽位**展开，起点是一个需要 Panel 类型的空槽。
每个动作填一个字段、算子、离散窗口或常数，并产生所需子槽；没有未完成槽时表达式结束。
同一有序 AST 只有一种生成路径，反向概率 P_B=1，避免多条生成路径造成额外的路径计数偏差。
运行时可以去重、共享执行 DAG，但不能在训练中随意合并前缀、同时继续假设 P_B=1。

状态包括：部分 AST、槽位类型、剩余长度、可用历史长度，以及冻结组合的条件向量。
条件向量由成员 AST/权重的无序集合编码、收益/回撤/风险暴露摘要、行为档案摘要构成。
原始回测缓存以版本 ID 定位；不能只把 ID 作为能推断组合性质的特征。
早期先不加 AlphaRJM 的 SDE critic；是否加入近期接受/拒绝事件编码做单独消融。

前向策略：

    πθ(a | partial_AST, slot, portfolio_context, preference)
        = masked_softmax(network_logits)

例如生成 `gt(ts_mean(feature,20),threshold)`：选择 gt → 选择 ts_mean → 选择字段 → 选择 20 → 选择阈值。
下一次可以直接生成另一棵树，不需要先挑两个父本交叉。这与 GP 的产生后代机制有实质区别。
上例只说明 DSL 构造步骤，不声称它是有效 alpha。

掩码排除类型不匹配、未来引用、无效窗口、剩余长度无法闭合的动作。
不要用主观经济学规则禁止所有“看起来不合理”的结构；文法合法也无法保证有限数值、可交易或 G2 通过。
不要沿用旧研究原型 max_len=5 等未经本目标验证的限制。

### 参数如何生成

初版窗口、常数使用有界离散词表，避免把连续密度、取整窗口和离散概率混在同一个 TB 实现中。
可再对选中的结构做有预算的连续参数搜索：阈值用截断分布采样、按真实组合奖励更新分布；整数窗口仍显式离散。
这是交叉熵法/分布估计算法（CEM/EDA）的参数优化，不把它称为新的生成算法。
阈值引发不连续持仓时，不假设可以对整个回测可靠求梯度。

### 怎么学习

对完整轨迹 τ，以条件化归一化量 Zϕ(c) 训练：

    L_TB = [log Zϕ(c) + Σ_t log πθ(a_t|s_t,c) - log R(x|c)]²

这里 P_B=1 是上述唯一展开规则的结果。一般有多个反向动作时必须加入 -Σlog P_B。
理想拟合目标为 p(x|c)∝R(x|c)，实际小模型、有限训练和熵正则会有偏差；不声称样本已经精确服从该分布。
多样性来自奖励、行为去重和探索共同作用，不能仅靠“GFN 会多样化”这句话。

## 6. 让快回测提供动作级反馈

AlphaG-OPD 提供了本轮最值得验证的具体机制。
对一个部分 AST，选择当前动作及两个类型/元数/后续槽兼容的兄弟动作。
在三个分支共同允许的支持集上抽取四条共享补全序列：

| 后续补全 | 动作 a₁ | 动作 a₂ | 动作 a₃ |
|---|---|---|---|
| u₁ | 回测 R₁₁ | 回测 R₁₂ | 回测 R₁₃ |
| u₂ | 回测 R₂₁ | 回测 R₂₂ | 回测 R₂₃ |
| u₃ | 回测 R₃₁ | 回测 R₃₂ | 回测 R₃₃ |
| u₄ | 回测 R₄₁ | 回测 R₄₂ | 回测 R₄₃ |

比如均值与其他同类型一元滚动统计的选择，必须用相同字段、窗口及其余子表达式比较。
不是分别随机生成三棵完全不同的树再把收益差归功于第一个算子。
共同合法支持过窄则放弃该探测；不同元数或不同槽类型的动作不能硬凑成配对。

原文采用三分支策略的几何平均形成共享补全提议 q，并计算：

    C_ki = log R(x_ki) - log q(u_k | s, {a₁,a₂,a₃})

q 对同一行三个动作相同，配对差中抵消；这不是无偏 log-flow 估计。
按中心化均值信用 c_i 对原分支概率 p_i 进行指数倾斜：

    teacher_i ∝ p_i exp(α c_i / τ)

限制相对原策略的 KL，只有四行中至少三行选出相同赢家，且配对再分配收益的经验下界 mean(Δ)-SE(Δ)>0 才教学。
原文 τ=1、KL 半径上限 0.03，再按可靠性缩小；辅助损失是教师到当前前向策略的 KL。
四个补全的经验下界不是 95% 金融置信度，也不是四个独立市场样本。

**Q25 改造要求：12 个格子必须使用完全相同的组合版本、相关性档案、数据和目标尺度。**
不能评价第一个候选后就入库再评价第二个，否则比较失去意义。
共同补全减少部分比较噪声，但也可能遗漏不同分支各自最优的后续搭配；它是局部学习信号，不是算子全局优劣证明。

原文 10000 次物理评价预算中，8008 次普通轨迹、1992 次探测（166×12）。
Q25 可从约 20% 探测预算开始，与 0%/10% 比较；不能把 12 次评价算成“一个样本”来虚报样本效率。
探测本身耗费算力，只有增加有效低相关通过者或组合收益才值得保留。

## 7. 组合改变时怎样继续学

每个搜索 epoch 冻结组合 P_v、档案 A_v、数据切分、精度合同、目标尺度和采样策略快照。
批量采样/探测、回测、训练完成后，再选一个候选进行 FP64 准入并更新组合。

所有记录保存：

    AST, trajectory, data_version, split, portfolio_version,
    archive_version, reward_config, precision_contract, metrics

组合改变后：

- 因子值、持仓与单体收益缓存可在数据及执行合同不变时复用。
- 组合增量、相关性奖惩、teacher 目标必须重评或过期，不能把旧数值作为新参照的标签。
- 历史上下文样本只能带着原上下文训练；若把它重标成当前上下文，必须重算奖励。
- Z 也要条件化；不能拿单个全局常数假装不同组合的奖励分布未改变。

原文教师回放 512 行、1000 次物理评价后过期，是单论文配置；Q25 组合变化时应更早失效。
行为档案增删也会改变新颖度奖励，所以只锁组合还不够。

## 8. 直接优化组合，不停在“筛一条加一条”

外层是近似的列生成/交替优化：生成器提出新的持仓构件，组合优化器决定是否接纳及如何分配权重。
这借用了列生成思想，但非凸 Sharpe、成本和门槛条件下，不声称有传统凸列生成的收敛保证。

第一步保持现有添加路径：每个构件必须相对于当下 P_v 通过 G1/G2，再选低相关者加入。
第二步增加**已有成员联合重配与淘汰**，否则旧权重比例锁死会限制可达到的组合。

一个不依赖回测可微性的明确重配算法是单纯形上的交叉熵法：

1. 从当前权重出发，对 logits 的高斯分布采样，以 softmax 映射成非负、和为 1 的权重；当前权重始终保留为可选项。
2. 批量构建真实组合持仓，在 CUDA 上扣成本回测；按 G2 可行性优先、再按 U 选择精英。
3. 用精英 logits 更新均值和对角方差，保留最小方差和一定探索；固定迭代/评价预算，避免无限拟合。
4. softmax 不能产生严格零权重，因此另行生成少量“删一成员并重新归一化”的候选，再用同一评价器比较。
5. 对最终候选用 GPU FP64 复核；无可行改善则保留原组合。由通过方案更新权重与参照版本。

这是明确的 CEM 权重优化子算法，不是把整个系统统称“机器搜索”。建议和简单成对权重转移做成本对照。
联合重配不能借用线性单体净收益近似作为最终判定。

进一步可以一次提出两个互补构件，但“两个单独失败、合起来通过”属于**组合包准入**，改变了逐构件 G2 语义。
当前用户要求产出的构件能通过 G1/G2，因此首版不允许以组合包绕过单构件准入；若研究这一扩展，单独标识协议与指标。
历史接受成员也不可能永远再相对最终组合获得同样的边际改善；应报告接受当时的 G2，以及最终组合的成员删除贡献。

## 10. 吞吐与实现边界

例如同时采样 256 条平均长度 16 的表达式，是约 16 次批量网络前向，而不是 4096 次逐候选模型调用。
64 个局部探测会增加 768 次终端评价；这里“终端评价”内部仍包含多个组合权重试探。
这些是工作量示例，**没有测得新生成器每秒条数**。长度差异需掩码/分桶处理。

生成 batch、回测持仓 batch、训练 batch 分别配置。256 条表达式可以切成多个适合本机 4 GiB 显存的评价批次。
不能因为 AST 很小就把 256 份时序持仓全部塞入设备。
策略采样、训练和回测竞争同一 GPU，先限制训练占用并测端到端吞吐，不能假设异步必然免费。

C++ 负责 AST、掩码、队列、去重索引；CUDA/LibTorch C++ 等实现张量运算、网络前后向与真实评价。
Python 只负责调用和记录，不在每候选热路径执行数值循环，也不引入生产 CPU 回测。
网络可首先用 FP32，回测沿用已实现的误差预算 auto/FP64 准入；任何更低精度应以误差及决策稳定性验证为依据。
FACT 对可复用子图/kernel 组合的启发是执行层优化，不是 alpha 搜索算法，也不保证新表达式有预测价值。

## 11. 如何证明值得进生产

先固定同一 DSL、数据可见范围、初始组合、G1/G2、相关性政策、精度合同与总资源。
至少比较：

| 组别 | 目的 |
|---|---|
| 有类型随机采样 | 看合法空间本身能提供多少有效构件 |
| GP + 相同组合奖励/去重 | 对照之前的实际算法，不把旧的单体 CPU 目标当弱基线 |
| 文法规则概率 CEM/EDA | 检查简单精英频率学习是否已经足够 |
| 条件 GFN | 衡量学习多模式生成分布的增益 |
| 条件 GFN + 配对教师 | 衡量额外探测能否抵偿被占用的普通评价预算 |
| 上一组 + 联合重配 | 区分表达式生成改进与权重优化带来的收益 |

学习型方法另做“有/无组合上下文”消融。所有方法拿到同等去重、混合精度和编译缓存机会。
以固定物理回测预算和固定墙钟预算分别比较，计入预训练、采样、JIT、网络训练、重复检测和重配耗时。
重复缓存命中、唯一持仓数、完整回测数及权重试探数分别记录，不能混成一个 candidates/s。

主要指标：**每秒新增且低相关的 G2 通过者、固定预算后的组合 Sharpe/收益改善**。
同时记录通过率、行为重复率、相关性/共同亏损分布、GPU 等待时间、显存、FP64 升级率以及不同种子分散程度。
先小预算排除供给/训练瓶颈，再在相同总预算下至少运行 5 个种子；不要只展示最好的一次。

通过 G1/G2 是历史数据上的准入，不是未来盈利证明。当前历史已被多轮挖掘看过，重新切分不能把它变成真正未见样本。
可以用时间块做稳健性诊断，但不要称为干净样本外；真正未见评价需冻结模型/组合后等待新增时间数据。
如果在未来全新数据任务中采用训练/选择/最终留出，需按时间划分并处理跨界窗口和标签；整个搜索过程不得反复读取最终留出。

本文未运行新挖掘、未启动云端、未调用子 agent，也未修改 gate。下一次实现应以本规格的一个可比较版本为单位推进，不能直接将论文收益当作生产验收。
