# 独立 Agent 接入：非公式候选

[English](README.md) · [接入指南](../../research.zh-CN.md) · [结果证据](evidence.json)

GPT-6.1 Sol 仅依靠公开文档与运行时接口发现，独立完成了两批共六个非公式候选的接入：自定义数值因子和 GPU 岭回归模型。注册、评价、根据反馈调整、家族检查、保留、释放和持久引用重评均完成。六个候选全部未通过组合硬准入；这次没有验证提交执行，也没有发现可据此宣称有效的策略。

## 接入条件

- 引擎版本 `28ed260`；一张 Colab NVIDIA L4，双 FP32 计算，独立临时组合。
- 美股 491 个资产，含历史共 148 个网格日期，评价区间为 2025-07-01 至 2025-12-31，共 128 日。
- Sol 只阅读公开规范、README、研究/数据指南及运行时 schema 和签名，没有阅读 Foundry 实现、验证示例或既有 benchmark 报告。仅导入公开 `foundry` 入口。
- 主 agent 准备服务；Sol 自己编写、运行独立 RPC 客户端。因子与模型计算使用 L4 上的 CuPy，文件读取、坐标对齐和 NumPy RPC 传输使用主机。这次不是 RPC 零拷贝或驻留反馈测速。

## 候选与反馈调整

| 轮次 | 候选 | 单独回测 Sharpe | 硬准入 |
| --- | --- | ---: | --- |
| 首轮 | 波动率缩放的 10 日动量 | -0.586622 | G2 拒绝 |
| 首轮 | 上述动量的反转 | 1.826576 | G2 拒绝 |
| 首轮 | 历史前缀训练的岭回归 | 0.194832 | G2 拒绝 |
| 调整 | 波动率缩放的 5 日反转 | 0.939320 | G2 拒绝 |
| 调整 | tanh 压缩的 5 日反转 | 0.935967 | G2 拒绝 |
| 调整 | 因果评分校准后的岭回归 | 0.144209 | G2 拒绝 |

岭回归使用三个因果特征和 25,301 个有效资产/日期训练观测。训练标签最晚到网格第 73 行，预测从第 74 行开始，更早位置保持缺失；注册时如实声明观测和拟合截止点。调整后的模型只用训练期预测标准差校准评分尺度。Sol 根据首轮反馈缩短反转周期，但未超过首轮反转表现。

这是研究期内的反馈调整，不能视为独立样本外验证。历史数据缺少公告时间与修订版本；客户端的因果截止点不能弥补数据源本身的限制。

## 已验证范围与限制

六个结果均为 `ok=true`，准入原因均为 `constraints_failed`。两点 `CandidateGrid` 检查完成，通过率为零；样本过小，不能据此声称稳健。六个候选均经显式保留、释放临时租约后以持久引用重评，前后指标完全一致，组合来源、权重与上下文未变。客户端正常退出，L4 已释放。

实际未调用 `session.commit`：自动审批因这批候选均已被拒绝、提交授权不够明确且可能产生非预期发布而拦截。Sol 跳过该步骤，没有重试或绕过；因此不能把提交记为验证通过。本轮未采集分段计时，不作速度结论。

## 接入障碍与修正

Sol 最初误将 `describe()` 的字典传给 `foundry.export`，收到 `TypeError: asdict() should be called on dataclass instances`，随后在客户端改用 `json.dumps`，无需修改引擎。

主要文档缺口是信号尺度：首轮岭回归平均敞口仅 0.0387%，因为评分直接影响持仓，接口不会自动排名或补足投资预算。双语指南现已说明该映射，并明确评价成功与准入通过的区别，以及字典和强类型报告各自的导出方式。人类、Agent 和机器学习程序都能使用同一数值候选入口。
