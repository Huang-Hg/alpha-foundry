# L4：时间策略与公开接入验收

[English](README.md) · [原始指标](summary.json) · [逐阶段耗时](stages.csv)

**双 FP32 完整流程通过；轻量 FP32 对照未达标。** 同一张 NVIDIA L4（23034 MiB），8 个合成加密资产、2 天 5 分钟行情、192 个 15 分钟决策、576 个执行事件、48 个小时统计点。每条件一次，没有额外预热或三种随机种子重复。

误差来自同一数据、候选、顺序与双 FP32 的 CPU 正确性重放；没有使用 GPU 主机 CPU 作速度基线。指标归一化误差是 abs(error)/max(1,abs(reference))，既有容差未放宽。程序单独评价产生 346 次实际成交；目标执行器未提供成交计数，记为不可用。两组压力候选均未通过组合硬准入；下面的独立接入用例验证了真实接纳。

查询包含候选执行、统计和组合权重试算；提交按顺序重新判定并原子发布组合。完整生命周期另含打开/加载/JIT、候选生成、注册、必需保存、显式保留、证据写盘和资源关闭，不含独立 CPU 正确性审计。峰值显存为 20ms 采样下界。

## 精度对照：保留失败结果

64 数组的轻量 FP32 对照最大收益误差为 4.27e-7，但年化和 Sharpe 等指标超限，并出现 2 个准入子判据差异（同一候选在查询与提交各一次）。16 程序的 shared/independent 对照也有指标、试探权重差异；最终基准组合的成交次数相差 18 次。最终入选集合虽然相同，仍不满足指标和事件一致性要求。

这些原始失败完整保留。双 FP32 的 16 程序 CPU/CUDA 收益逐位相同、指标最大归一化误差 1.15e-10、判定一致，所以全规模只运行预先选定的双 FP32。没有按单个候选结果切换精度或复算，未运行不合格精度的全规模条件。这不是宽精度的 1.5× 资格测试。

## 独立 Agent 与回归

GPT-6.1 Sol 仅按公开文档编写接入客户端，唯一项目导入为 `foundry`。4 个混合候选完成 GPU 反馈学习、直接提交、保留/释放和重新打开，完整用例 115.708 秒。两个非公式数组因子依次入选为权重 1；后者替代前者。程序按实际库存完成买入和平仓，共 2 次成交。一次样本内 chooser 更新仅证明反馈接口可用，不代表模型训练或样本外收益结论。

508 项检查通过，1 项旧私有生产基线跳过。四市场各 4 个日线公式的指标、风险、决策及有序权重与 R4 `6c94ead` 精确一致，仅排除协议身份和新增空成交计数字段。程序暂停/恢复、未完成统计周期、挂单、资金费和强平在 CPU/CUDA 上通过对照。初次 smoke 的两个夹具问题经定向修复，其失败日志仍保留。
