# L4：消除有状态程序评价到提交间的重复重放

[English](README.md) · [汇总指标](summary.json) · [分段耗时](stages.csv)

在 256 个有状态程序压力批次上，「查询＋有序提交」耗时从 **42.301 秒降至 20.851 秒（2.03×）**；从打开会话到关闭资源的完整生命周期耗时从 **44.496 秒降至 23.116 秒（1.92×）**。收益序列、各项指标、成交/风险摘要、选中权重与准入结论完全一致。

**适用边界：本组压力候选全部被硬准入拒绝。** 约 2× 的提速来自当 `ResearchContext` 未变时直接复用会话自身刚完成的评估与权重试算元数据，省去第二次重复回放。一旦前置候选入选导致组合演进，后续候选仍须对照新组合重新重放（状态发生变化的实测见 [L4 连续入选与组合调权](../program-transitions-l4-20261117/README.zh-CN.md)）。回归测试已覆盖前置接纳失效、RPC 同构、调用方篡改报告、租约释放与原子写盘失败等分支。

## 方法与正确性

同一张 NVIDIA L4（23,034 MiB，驱动 580.82.07），每项条件测量一次，共用同一套基准夹具、原生内核、数据与参数：8 个合成加密现货资产、2 天 5 分钟基础 Bar、192 个 15 分钟决策、576 个执行事件、48 个小时统计周期；双 FP32 算术，显式设置 `Admission(weight_steps=4)`（生产默认配置不变）。

- 收益数组逐位一致；所有报告字段最大绝对误差与准入决策差异均为 0。
- 521 项测试与 8,778 个子用例通过，1 项旧协议私有生产基线按约定跳过（未重录覆盖）。
- 美股、A 股、加密现货与永续四市场各 4 条日线公式在指标、风险、准入结论及有序权重上完全一致。
- 会话仅保留最近一个候选批次的主机端报告摘要，不保留收益数组、持仓、活动账户或历史批次。
- 完整生命周期包含加载/规划/JIT、候选生成、注册、评价、提交、持久化保留、导出、释放与关闭；峰值显存为 20 ms 采样下界。
