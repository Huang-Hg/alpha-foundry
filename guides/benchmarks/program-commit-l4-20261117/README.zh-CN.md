# L4：减少程序评价到提交间的重复重放

[English](README.md) · [汇总结果](summary.json) · [分段耗时](stages.csv)

256 个有状态程序的查询＋有序提交从 **42.301 秒降至 20.851 秒（2.03×）**；包含打开会话到关闭的完整生命周期从 **44.496 秒降至 23.116 秒（1.92×）**。收益、指标、成交/风险摘要、权重与准入结论无差异。

## 方法与正确性

同一张 NVIDIA L4（23,034 MiB，驱动 580.82.07），每条件运行一次，共用同一基准驱动、原生核、数据与参数：8 个合成加密现货资产，2 天 5 分钟 Bar、192 个 15 分钟决策、576 个事件、48 个小时统计周期。双 FP32 算术，显式设置 `Admission(weight_steps=4)`，生产默认值未改；未采集新的 CPU 计时基线。

- 收益数组逐位一致；所有报告数值最大绝对误差与决策差异均为 0。
- 521 项测试与 8,778 个子测试通过；1 项旧私有生产基线跳过，未重录。
- 美股、A 股、加密现货和永续各 4 条日线公式在指标、风险、准入与有序权重上一致。
- 仅保留最近一批主机端报告摘要，不保留收益数组、持仓、活动账户或历史批次。
- 完整生命周期包含加载/计划/JIT、生成、注册、评价、提交、保留、导出、证据写盘、释放与关闭。峰值显存为 20 ms 采样下界。
- 相邻检查复用同一 L4 会话，取回结果后释放。单次测量不代表统计置信区间。

## 复现说明

测量时将规模 16 与 256 拆为连续步骤，先通过小规模再运行大规模，未重复测量。基线恢复 `cc0f2b4` 的两个 `study` 文件，基准驱动与其余文件共用同一版本。公开数据见 [summary.json](summary.json) 与 [stages.csv](stages.csv)，原始日志与归档包保存在本地 `var/runs/`。
