## 空间与速度取舍

PRO 6000 上，上一版 8192 MiB 完整持仓缓存的采样峰值为 11886.2 MiB，本版为 8156.2 MiB；评价＋提交从 2.3515 秒变为 2.7855 秒。旧版与本版的 4096 公式报告数值变化为 0，研究快照、决策和最终权重相同。历史数字来自前一台 Colab PRO 6000 会话，属于同型号对照。

只缓存 `(T,)` 收益和标量报告，不缓存候选 `(T,S)` 持仓或语法树；接纳成员复制自身数据，避免切片继续持有整批数组。持久缓存空间为 `O(C + (b+M)TS)`：C 为缓存预算，b 为执行批量，M 为成员上限，T/S 为天数/资产数。临时表达式和配权工作区另受算子代价、trial_batch 限制。公开报告仍需 O(N) 主机空间；显式驻留设备接口返回的 O(NTS) 输出由调用方持有。

## 误差与测量边界

66 算子、124 个窗口条件在每张卡均通过 CPU 对照，符号与 NaN/无穷掩码一致。跨 GPU 及小缓存改造前后的报告最大绝对变化为 7.28e-12；相对 PRO 主机 CPU 的最大尺度化报告误差为 7.41e-07，无容差超限或决策变化。详见 comparisons.json 的逐字段最大误差。

PRO 6000 完整验收：563 passed、1 skipped、7186 subtests passed，包含资金费与强平边界回归。各设备先跑四市场候选、缓存/CAS 和算子 smoke，再各条件一次预热、一次实测；其他卡没有重跑完整永续边界套件，没有重复种子。私有生产基线未重录且明确跳过，算术精度未更改，独立单精度 1.5× 预算未重新验收。

执行批量 256、配权批量 16384、8 条流、paired 算术；OMP/OpenBLAS 各 2 线程。不同 Colab VM 的主机 CPU 不同，端到端数字包含 Python/主机工作，单次结果不是纯 GPU 核心排名。逐卡硬件及软件信息见 benchmark.json/device.txt。H100 申请返回 HTTP 503，没有 H100 测量。

复现 PRO 全套：

```bash
OMP_NUM_THREADS=2 OPENBLAS_NUM_THREADS=2 python -m foundry --parameters '{"market":"us_equity"}' benchmark var/runs/compact --sizes 64 256 1024 4096
```

其他卡复用同一 pytest 基准，只筛选算子和 CUDA 完整流程，避免重复耗时的 CPU 大批量流程；确切命令见 cloud-job.py。源代码哈希标识本次实际工作区，benchmark.json 中 Git 信息是 Colab 克隆的基础版本。
