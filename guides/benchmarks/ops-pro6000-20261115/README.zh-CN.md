# CUDA 滚动算子优化对比

[English](README.md) · [完整对比 CSV](comparison.csv) · [优化前报告](baseline/report.zh-CN.md) · [优化后报告](optimized/report.zh-CN.md)

在同一台 RTX PRO 6000 与 `269 日 × 500 资产` 美股面板上，对比分块滚动核改动前后全部 66 个算子、124 个窗口条件的单次调用耗时与精度。4,096 条公式的「评估＋有序提交」耗时为 `2.8047 秒` 对比 `2.7699 秒`（约 `1.2%` 波动，单次观测不构成统计显著差异）。

| 算子（窗口 20） | CPU（微秒） | CUDA 优化前（微秒） | CUDA 优化后（微秒） | CUDA 比值 |
| --- | ---: | ---: | ---: | ---: |
| `ts_std` | 240.05 | 437.27 | 233.44 | 1.87× |
| `ts_slope` | 132.51 | 325.81 | 236.41 | 1.38× |
| `ts_av_diff` | 87.60 | 195.70 | 121.42 | 1.61× |
| `ts_backfill` | 33.13 | 76.33 | 22.51 | 3.39× |
| `ts_ref` | 27.72 | 28.21 | 19.05 | 1.48× |
| `ts_delta` | 37.16 | 34.71 | 20.53 | 1.69× |
| `ts_corr` | 1101.91 | 872.47 | 421.53 | 2.07× |
| `ts_cov` | 701.61 | 448.81 | 318.29 | 1.41× |

窗口 `2 / 20 / 120` 的全部数据见 [comparison.csv](comparison.csv)（每条件预热 1 次、测量 1 次）。在单张 `(269, 500)` 小面板的单算子调用下，受内核启动延迟影响，仍有 20 个简单逐元素与短窗口算子共 24 个条件单次 CUDA 调用慢于 CPU（`abs`、`add_const`、`div`、`gt`、`inv`、`is_nan`、`left_tail`、`mul_const`、`neg`、`not`、`not_equal`、`right_tail`、`sign`、`square`、`sub`、`ts_av_diff`、`ts_backfill`、`ts_skew`、`ts_slope`、`ts_std`）。

递推核按输出时间行分块并在块内保持原始时间顺序累加，避免极值滑出窗口后留下相消残差；`ts_backfill` 改为并行向后查找，`ts_ref` 与 `ts_delta` 各合并为单次内核启动。改动前后 CUDA 在 `1 / 64 / 4,096` 条公式上的准入结论、权重与最终组合零差异（有效 `4,058` 条、入选 `28` 条），560 项测试（7,159 个子用例）通过。
