# Foundry 与 Spectre、vectorbt、Freqtrade 横向对比

[English](README.md) · [详细报告](report.zh-CN.md) · [汇总 CSV](summary.csv) · [对比方法与复现环境](../../framework-benchmark.zh-CN.md)

在这组受控日线现货 SMA 基准测试中，**Foundry CPU 在全部测试规模下端到端最快**；在 64 候选规模下，Foundry CUDA 耗时 `0.145 s`，显著快于 vectorbt Numba（`0.268 s`）、Freqtrade（`14.023 s`）与 Spectre（`66.445 s`），但在单候选极小批量下因内核启动开销慢于 vectorbt。所有条件均在同一台 Colab RTX PRO 6000 Blackwell Server（CPU 固定 2 线程）上预热一次、测量一次，仅代表该受限工作负载下的单次实测观察。

共同输入为 **8 个加密现货资产、549 根 UTC 日线、365 个交易日**（`BTC`、`ETH`、`SOL`、`BNB`、`XRP`、`ADA`、`DOGE`、`LTC`），每个 `(候选, 资产)` 对拥有独立账户；因果 SMA 突破信号在 `open[t+1]` 按前收盘价动用 25% 现金买入、在 `open[t+2]` 全部卖出，最大规模覆盖 **512 个独立账户、48,032 笔成交**。

## 数值精度与成交核对

- **交易信号与成交身份零差异：**全部 36 个正式测试条件中，入场决策与成交事件身份（候选、资产、日期、方向）**0 差异**；期末全部空仓，现金与账本独立核对通过。
- **零费净值精度：**相对 Foundry CPU，Foundry CUDA 最大归一化净值误差为 **`2.14e-13`**，三家外部框架不超过 **`4.89e-15`**（门槛 `1e-8`）。
- **单边 10 bps 含费精度：**Foundry CUDA 最大归一化净值 / Sharpe 误差为 **`1.57e-13` / `2.31e-12`**；Spectre 因原生 `SimulationBlotter` 将每笔手续费四舍五入至分位，净值 / Sharpe 差异为 **`9.13e-8` / `1.87e-6`**（每 100 万初始资金差额不足 `0.10`），原样保留并单列报告。
- **能力边界说明：**Foundry 目标现金核胜在紧凑循环与批量路径，但该目标模式下的成交记录由净值与单日持仓反推（标记为 `native_ledger=False`）；Spectre 与 Freqtrade 则执行完整的逐账户串行事件/钱包引擎，在简单目标脉冲任务上承担了额外通用开销。

公开逐条件明细见 [report.zh-CN.md](report.zh-CN.md) 与 [summary.csv](summary.csv)；完整逐账户原始数组与环境日志归档保存在本地 `var/runs/framework-evidence.tar.gz`。
