# Foundry 与 Spectre、vectorbt、Freqtrade 对比

[English](README.md) · [完整报告](report.zh-CN.md) · [CSV](summary.csv) · [对比方法](../../framework-benchmark.zh-CN.md)

在这组受控的日线加密现货 SMA 脉冲任务上，端到端耗时最短的是 Foundry **CPU** 后端；所测规模下 Foundry CUDA 未快于 Foundry CPU。64 候选时 Foundry CUDA 耗时 `0.145 秒`，对比 vectorbt Numba `0.268 秒`、Freqtrade `14.023 秒`、Spectre `66.445 秒`；单候选小批量下 vectorbt 快于 Foundry CUDA（`0.015–0.016 秒` 对比 `0.027 秒`）。各条件均在同一台 RTX PRO 6000 Blackwell Server（限制 2 个 CPU 线程）上预热 1 次、测量 1 次，仅反映该特定负载下的表现，不代表各框架的通用快慢排名。

输入为 8 个现货交易对（`BTC`、`ETH`、`SOL`、`BNB`、`XRP`、`ADA`、`DOGE`、`LTC`）、549 根 UTC 日线、365 个交易日，每个 `(候选, 资产)` 对使用独立账户。SMA 突破信号在 `open[t+1]` 按前收盘 25% 现金买入、在 `open[t+2]` 卖出，最大批次含 512 个账户与 48,032 笔成交，分别测试零费率与单边 10 bps 手续费。

## 端到端耗时（秒，单边 10 bps）

计入数据读取、原生指标与账户执行、公共指标计算及 `.npz` 写出；不含导入、预热与事后核对。

「原生流水线」列仅统计各框架的指标与账户执行及公共结果数组生成，不含后续公共指标归约与写盘。64 候选下 vectorbt Rust 原生流水线略快于 Numba（`0.194 秒` 对比 `0.200 秒`），但写出阶段耗时更长（`0.203 秒` 对比 `0.068 秒`）。GPU 显存每 20 ms 采样一次（含上下文与分配器缓存），可能漏过更短瞬时峰值。

## 数值核对与适用范围

全部 36 个测试条件中，入场信号与成交事件身份（候选、标的、日期、方向）零分歧，期末全部空仓且现金与账本核对一致。以 Foundry CPU 为参照，零费下 Foundry CUDA 最大归一化净值误差为 `2.14e-13`，外部框架不超过 `4.89e-15`（容差 `1e-8`）。单边 10 bps 下 Foundry CUDA 净值与 Sharpe 最大归一化误差为 `1.57e-13` 与 `2.31e-12`；Spectre 因原生佣金按分位四舍五入，对应差异为 `9.13e-8` 与 `1.87e-6`（每 100 万初始资金差额低于 `0.10`）。512 个含费账户总收益中位数为 `-7.26%`（`-19.50%` 至 `+10.67%`）。

本测试使用 Foundry 的目标仓位现金核（直接输出收益率，成交记录由净值与单日目标持仓反推，记 `native_ledger=False`），而 Spectre 与 Freqtrade 执行完整的串行事件/钱包引擎，在简单目标脉冲任务上带有额外事件调度开销。实验未涵盖共享资金池组合调度、止损单、股票规则、永续强平或 Foundry 的订单账户引擎；逐条件明细见 [report.zh-CN.md](report.zh-CN.md) 与 [summary.csv](summary.csv)。
