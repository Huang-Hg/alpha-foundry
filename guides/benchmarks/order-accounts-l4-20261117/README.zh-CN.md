# 订单账户：成交费率、全仓保证金与股票日内

[English](README.md) · [汇总数据](summary.json) · [程序接口](../../programs.zh-CN.md)

在单张 NVIDIA L4（23,034 MiB，驱动 580.82.07，CuPy CUDA 13 14.0.1）上测试逐笔 Maker/Taker 费率、USDT 全仓保证金及美股/A 股常规时段现金订单。125 项 CPU/CUDA 功能与数值一致性检查在合成用例上通过。

| 测量项 | 结果 |
| --- | ---: |
| 账户 × 事件 × 资产 | 17 × 16 × 2 |
| 算术精度 | 双 FP32 |
| 完整账户重放耗时 | 214.25 ms |
| 期末权益最大绝对误差 | 6.93e-12 计价单位 |
| 期末持仓最大绝对误差 | 0 |
| 测量轮数 / 每轮次数 | 1 / 1 |

计时包含行情缓冲准备、账户创建、订单指令、独立反馈拷贝、结果校验与关闭释放，内核准备与 JIT 在计时区间外。本轮未采样峰值显存，也不代表完整组合查询＋提交吞吐或 GPU 相对 CPU 的加速比。

测试覆盖立即成交与挂单等待的限价单、部分成交角色区分与 Maker 返佣；盈利持仓补充全仓保证金、资金费触发全账户强平与撤单；A 股 T+1 可卖库存、零股卖出与拆股后平仓；美股 T+1 卖出资金交收、当日有效单过期、节假日、午休、半日市与夏令时切换。美股和 A 股公式与数量数组的 CPU/CUDA 指标及准入结论在 `rtol=2e-5`、`atol=2e-6` 内一致。

全仓强平采用整账户平仓的 Bar 模型，不对应特定交易所的分档维持保证金梯度。股票订单面向常规连续竞价时段的现金账户；股息登记、融券与集合竞价等范围说明见 [guides/data.zh-CN.md](../../data.zh-CN.md)。
