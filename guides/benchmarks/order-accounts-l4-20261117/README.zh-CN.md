# 订单账户：成交费率、全仓保证金与股票日内

[English](README.md) · [结果](summary.json) · [程序接口](../../programs.zh-CN.md)

在同一台 Colab NVIDIA L4 上完成 maker/taker 逐成交费用、USDT 全仓保证金及美股/A 股常规交易时段现金订单验收。**125 项针对性检查通过**，覆盖 CPU/CUDA 功能一致性、公开公式/数组评价与提交决策、PIT、交易日历、结算及检查点恢复。数据为合成用例，不据此宣称实盘收益或真实市场表现。

| 单次 CUDA 计时 | 结果 |
| --- | ---: |
| 账户 × 事件 × 资产 | 17 × 16 × 2 |
| 算术 | 双 FP32 |
| 完整账户重放 | **214.25 ms** |
| 终值权益最大绝对误差 | **6.93e-12** 计价货币单位 |
| 最终持仓最大绝对误差 | **0** |
| 计时轮数 / 每轮次数 | 1 / 1 |

计时包含行情缓冲准备、账户创建、命令、独立反馈副本、结果断言与关闭；核准备/JIT 在计时外。它不是完整研究查询＋提交耗时，也没有与旧版或固定 CPU 性能基线比较。本轮未采样峰值显存。

检查覆盖立即成交/等待成交限价单、部分成交角色与返佣；多空盈利腿补充抵押、资金费触发全仓强平及撤单；A 股 T+1 可卖库存、零股、拆股后目标清仓；美股 T+1 现金、日订单过期、节假日、午休、提前收盘和夏令时。美股/A 股公开公式与数量数组流程的 CPU/CUDA 指标、准入和提交决策一致，指标容差为 `rtol=2e-5`、`atol=2e-6`。

首次用例收集因环境中同名 `tests` 包遮蔽而停止，未执行测试。随后 118 项通过，另 6 项遇到 CUDA 包版本冲突，1 项仍保留旧的股票订单拒绝预期；修正后仅重跑这 7 项，全部通过。验收后的计时只执行一次。原生构建和 Ruff 通过，未读取或重录私有生产基线。

设备为 L4 23034 MiB，驱动 580.82.07，最终使用 CuPy CUDA 13 14.0.1。119 个核心源码文件的云端/本地 SHA-256 全部一致。原始证据仅保留在本地 `var/runs/order-accounts-l4/evidence.tar.gz`，核对后已释放会话。

全仓采用明确的账户整体平仓 Bar 研究模型，不宣称复刻某交易所的风险档位。股票订单覆盖常规时段现金账户；股息权益、融券、竞价等边界见[数据契约](../../data.zh-CN.md)。
