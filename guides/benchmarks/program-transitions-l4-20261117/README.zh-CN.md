# L4：连续入选与组合调权

[English](README.md) · [汇总数据](summary.json)

改动前后候选收益误差、归一化指标误差与准入决策差异均为 `0`，权重试算可行性、选中权重向量、提交结果及调权前后组合收益完全一致。

连续入选场景中，前两个程序依次替换或增加标的敞口，后续候选针对更新后的组合重新评估。双成员调权场景从初始权重为 `0.25 / 0.25` 的双成员组合出发（不计入新增入选），独立账户总资金比例保持不超过 `1.0`，并覆盖过期报告触发 `ContextConflict` 拒绝及重评后再提交的流程。

研究耗时包含首次评估、有序提交、调权前评估、权重查询/提交、过期报告拒绝与调权后评估/提交；生命周期耗时另含初始化、加载/JIT、注册、导出、释放与关闭。输入为 8 个合成加密现货标的、576 个事件、192 个决策点、48 个统计周期，设置 `Admission(weight_steps=4)`；[summary.json](summary.json) 中的峰值显存为 20 ms 周期采样下界。首组 4 候选包含冷启动与首次编译耗时，16 候选行更接近稳态耗时；共享账户下的权重仅缩放订单申报数量（`2.0` 为数量倍率而非 200% 资金杠杆）。
