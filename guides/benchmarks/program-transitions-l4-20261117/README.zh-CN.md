候选收益最大绝对误差 **0**；指标最大尺度化误差 **0**；决策差异 **0**。权重试算可行性、选中向量、提交结论及调权前后组合收益均通过比较。

连续入选场景中，前两个程序依次替换／增加上涨品种敞口，后续控制候选仍按更新后组合判定。双成员调权场景从明确构造的历史组合开始，初始权重 0.25/0.25；该初始化不计入本轮入选。独立账户保持总资金分配不超过 1。所有场景验证旧报告冲突和重新评价后的提交。

研究耗时包含首次评价／有序提交、调权前评价、权重查询／提交、旧报告拒绝、调权后评价／提交。生命周期另含历史组合准备、加载／JIT、注册、导出、释放和关闭。峰值显存是 20ms 采样下界。8 个合成 crypto 现货资产、576 个事件、192 个决策、48 个统计周期；默认费用与准入门槛不变，权重试探明确为 4 档。单次测量不表示统计置信区间，也不代表多样化实盘策略的盈利能力。

新增 smoke：32 项通过。由 pytest 和 pytest-benchmark 执行；每个条件仅一次，无预热重复。原始工件保留本地，GitHub 只保留本摘要、完整指标 JSON 与源码校验和。

首次小规模任务在规范 JSON 校验处失败，尚未测量；修正本地驱动后复用同一 L4 继续，原失败日志保留。

首次 4 候选旧版本还承担了冷启动／编译开销，后续条件自然复用设备与编译缓存；16 候选数据更适合观察稳定流程成本。共享账户的权重是程序分配系数，2.0 不等于持仓使用 200% 资金。
