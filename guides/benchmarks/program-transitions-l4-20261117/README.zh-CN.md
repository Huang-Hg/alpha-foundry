## 数值一致性与测量口径

- **零误差对照：**候选收益最大绝对误差 **0**、指标最大尺度误差 **0**、准入决策差异 **0**；权重可行性、选中权重向量、提交结论与调权前后组合收益序列全部一致。
- **状态演进语义：**连续入选场景中，前两个程序依次替换/提高上涨资产敞口，后续候选严格对照更新后的组合重放判定；双成员调权场景从显式构造的历史组合（初始权重 `[0.25, 0.25]`，不计入新增入选）出发，独立账户总资金分配始终不超过 `1.0`。全部场景同时验证过期报告触发 `ContextConflict` 及刷新重评后的正常提交。
- **计时范围：**「研究流程」涵盖首次评估、有序提交、调权前评估、权重试算/提交、过期报告拒绝及调权后评估/提交；「完整生命周期」另计入历史组合构造、加载/JIT、注册、导出、释放与关闭。测试输入为 8 个合成加密现货资产、576 个事件、192 个决策、48 个统计周期，`Admission(weight_steps=4)`。
- **结果解读：**首组 4 候选基线包含冷启动与首次编译开销，后续条件自然复用设备与编译缓存，因此 16 候选行更能反映稳态工作流耗时。共享账户中的权重 `[2.0]` 表示订单意图缩放系数，而非 200% 资金杠杆。定向 smoke 通过 32 项检查；完整分段指标与实测源码 SHA-256 清单见 [summary.json](summary.json)。
