连续入选场景中，前两个程序依次替换或增加上涨标的敞口，后续候选按更新后的组合重新判定。双成员调权场景从显式构造的历史组合（初始权重 `0.25 / 0.25`）出发，该初始化不计入本轮新增入选。独立账户保持总资金分配不超过 `1.0`。所有场景均验证过期报告冲突拒绝及重评后的提交。

研究耗时包含首次评价、有序提交、调权前评价、权重查询/提交、过期报告拒绝及调权后评价/提交；生命周期耗时另含历史组合准备、加载/JIT、注册、导出、释放与关闭。[summary.json](summary.json) 中的峰值显存为 20 ms 采样下界。输入为 8 个合成加密现货资产、576 个事件、192 个决策、48 个统计周期，默认费用与准入门槛不变，显式设置 `Admission(weight_steps=4)`。单次测量不构成统计置信区间或盈利证明。

定向 smoke 共 32 项通过，由 `pytest` 与 `pytest-benchmark` 单次执行，无预热重复。原始工件保存在本地 `var/runs/`（含首次小规模任务在进入测量前因本地驱动规范 JSON 校验失败的日志，修正后复用同一张 L4 完成测量）；仓库仅保留本说明与 [summary.json](summary.json)。

首组 4 候选基线包含冷启动与首次编译开销，后续条件自然复用设备与编译缓存，16 候选数据更接近稳态流程成本。共享账户的权重是订单数量缩放系数，`2.0` 不代表 200% 资金敞口。
